# Bonding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One Session over several networks at once: per-packet striping by acknowledged per-link rate, in-order delivery, carriers bound to a network (Android, Windows).

**Architecture:** Three self-contained units in `transport/` (ack codec, reorder buffer, bond scheduler) wired into `Session` behind a control-message agreement; `netbind` gains per-network dialing with a platform binder; `TransportConfig.Network` carries the choice to every carrier. Apps add a profile switch and a per-carrier network, Android binds sockets with `Network.bindSocket`.

**Tech Stack:** Go 1.26 (core, gomobile), Kotlin Multiplatform + Compose (apps).

Spec: `docs/superpowers/specs/2026-09-30-bonding-design.md`.

## Global Constraints

- Old exits must keep working with new clients: nothing new in the hello; bonding only after `SubtypeBonding` is answered.
- Without bonding agreed, Session behaviour is byte-for-byte unchanged (no reorder buffer, flow-hash routing).
- Ack every 50 ms; ack map 512 numbers; in-flight timeout 2 s; rate window 250 ms, start 256 KiB/s, floor 16 KiB/s; reorder hold start 100 ms, clamp [20 ms, 500 ms], factor 1.5; reorder capacity 4096.
- Network names: `""`, `cellular`, `wifi`, `ethernet`.
- Bonding and networks stay on the device: never in `openflux://` links.
- Go code: gofmt; comments in the house style (full sentences, why not what).

### Task 2: Reorder buffer

**Files:** Create `transport/reorder.go`, `transport/reorder_test.go`.

**Interfaces — Produces:**
```go
type reorderBuffer struct{ /* next uint64, pending map[uint64][]byte, hold time.Duration, ... */ }
func newReorderBuffer(deliver func([]byte)) *reorderBuffer
func (r *reorderBuffer) push(seq uint64, p []byte, now time.Time) // delivers what became in order
func (r *reorderBuffer) tick(now time.Time)                        // skips gaps older than hold
func (r *reorderBuffer) holdTime() time.Duration
func (r *reorderBuffer) reset()
```
Rules: first push sets `next = seq`; `seq < next` is delivered at once (late after a skip; the replay window already dropped duplicates); in-order runs deliver immediately; a gap records `gapSince`; `tick` past `gapSince + hold` advances `next` to the smallest pending and delivers the run; a filled gap updates hold = clamp(ewma(lateness)*1.5, 20ms, 500ms) with ewma α=1/8, lateness = now-gapSince; more than 4096 pending flushes in order.

- [ ] Tests (fake clock): in order passes straight; 1,3,2 → 1,2,3; 1,3 then tick after hold → 1,3 and later 2 still delivered; hold adapts up after late fills and stays in [20ms,500ms]; overflow flushes.
- [ ] Run → FAIL; implement; run → PASS.
- [ ] Commit `transport: reorder buffer for bonded sessions`.

### Task 3: Bond scheduler

**Files:** Create `transport/bondsched.go`, `transport/bondsched_test.go`.

**Interfaces — Produces:**
```go
type bondScheduler struct{ /* per link: inflight, rate, delivered window; sent map[uint64]sentPacket */ }
func newBondScheduler() *bondScheduler
func (b *bondScheduler) pick(links []string, size int, now time.Time) string
func (b *bondScheduler) sent(seq uint64, link string, size int, now time.Time)
func (b *bondScheduler) acked(a control.BondingAck, now time.Time)
func (b *bondScheduler) expire(now time.Time)            // drops packets in flight > 2 s
func (b *bondScheduler) linkStats() map[string]BondLinkStats
type BondLinkStats struct { RateBps float64; InflightBytes int; RTT time.Duration }
```
`pick` returns the link minimizing `(inflight+size)/rate`, ties by order; unknown links start at 256 KiB/s. `acked` credits delivered bytes into the current 250 ms window; closing a window folds `bytes/0.25s` into the rate EWMA (α=1/4), floored at 16 KiB/s.

- [ ] Tests: two links, acks delivered at 3:1 byte rates over 2 s of simulated time → `pick` share ≈ 3:1 (±15%); a link with no acks for 2 s drains its in-flight via `expire`; unknown link gets picked when others are loaded.

### Task 4: Session glue

**Files:** Create `transport/session_bonding.go`, `transport/session_bonding_test.go`; modify `transport/session.go`.

**Interfaces — Produces:**
```go
func (s *Session) SetBonding(on bool)          // client: offer bonding; call before Start
func (s *Session) Bonding() bool               // agreed with the current peer
func (s *Session) BondStats() map[string]BondLinkStats
```
Behaviour:
- Session fields: `bondOffer bool` (client wants it / exit supports it: exits always true), `bondAgreed bool`, `bond *bondScheduler`, `reorder *reorderBuffer`, `ack control.BondingAck`, `ackDirty bool`.
- `receiveControl`: `SubtypeBonding` → exit: set agreed, answer `SubtypeBonding` on the same link; client: set agreed. `SubtypeBondingAck` → `bond.acked`. Both handled inside Session like LinkPing (not passed to the manager).
- `keepaliveLoop` tick and handshake completion: client with `bondOffer && !bondAgreed` sends `SubtypeBonding` via `SendControl`.
- `resetLocked` (new peer): `bondAgreed=false`, fresh scheduler/buffer/ack.
- `Send`: when agreed, choose `bond.pick(names of liveLinksLocked(), len)`, then `bond.sent(seq, ...)`.
- `receiveIPv4`: when agreed, `ack.Set(seq)`, `ackDirty=true`, and `reorder.push(seq, payload)` (deliver = dataCallback) instead of calling back directly.
- A 50 ms ticker goroutine (started in `Start`): when agreed: `reorder.tick`, `bond.expire`, and if `ackDirty` send `SubtypeBondingAck` with the map via `SendControl`.

- [ ] Tests with two `asyncPair`s per side and a rate/latency-limited wire (add `slowWire` helper in the test: delay d, bytes/s cap):
  - bonded client + exit: 2000 packets of one flow arrive complete and in order; both links carried ≥20% each;
  - client with bonding vs exit built with `bondOffer=false` (old exit stand-in: ignores SubtypeBonding): no striping (all on the flow-hash link), delivery unchanged;
  - kill one link mid-stream (wire down): the rest arrives, no gap longer than hold + 1 s;
  - existing session tests still pass.
- [ ] Run → FAIL; implement; run `go test ./transport/...` → PASS.
- [ ] Commit `session: bonding over several carriers`.
